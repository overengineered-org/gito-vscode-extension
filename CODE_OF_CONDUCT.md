# Code of Conduct

Git'o follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Be respectful, specific, and focused on improving the project. Harassment, discrimination, personal attacks, publishing private information, and sustained disruption are not accepted.

Report conduct concerns privately through
[GitHub Security Advisories](https://github.com/overengineered-org/gito-vscode-extension/security/advisories/new).
Maintainers will review reports fairly, protect reporter privacy, and apply proportionate corrective action.

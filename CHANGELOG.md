# Changelog

All notable Git'o changes are published in GitHub Releases. Release versions
follow Conventional Commits: `fix` is a patch, `feat` is a minor release, and
breaking changes are major releases.

## [Unreleased]

- Added a local-first Git workbench with repository Home, changes, commits,
  branches, worktrees, fetch, pull, push, and sync workflows.
- Added premium diff and conflict-review flows with native VS Code editors,
  side navigation, review options, and guarded resolution actions.
- Added compare and search, commit graph, history and blame, contributors,
  and optional GitHub pull-request context.
- Added guided onboarding, optional VS Code provider sign-in, trusted-workspace
  mutation boundaries, and release/security verification workflows.

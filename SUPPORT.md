# Support

Open the matching
[GitHub issue form](https://github.com/overengineered-org/gito-vscode-extension/issues/new/choose).

Include:

1. Exact Git'o and VS Code versions.
2. Operating system and local, remote, or worktree context.
3. Repository shape without private names or URLs.
4. Smallest reproduction steps.
5. Sanitised screenshot and **Git'o** output when useful.

Report security problems privately through
[GitHub Security Advisories](https://github.com/overengineered-org/gito-vscode-extension/security/advisories/new).
